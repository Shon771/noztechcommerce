# NozTechStore — Telegram E-Commerce Bot

A personal software project focused on building a Telegram-based commerce system for small businesses.

## Overview

NozTechStore is a Telegram bot designed to help customers interact with a business through Telegram.

The project includes:

- Interactive Telegram bot menus
- Product catalog interaction
- API integration
- Backend services
- Database management
- Order and payment-related backend logic
- Automation-ready architecture

## Tech Stack

- Node.js
- NestJS
- TypeScript
- Telegram API
- REST API
- PostgreSQL
- Prisma
- Git

## Project Structure

The backend is organized into modular services for:

- Customers
- Products
- Cart
- Orders
- Payments
- Fulfillment
- Promotions
- Telegram interactions

## Telegram Bot

The Telegram layer includes:

- Start handler
- Main menu
- Product catalog interaction
- Callback routing
- Customer interaction flow
- Admin-related bot functions

## Purpose

This project was developed as a practical portfolio project to build experience in backend development, chatbot development, API integration, database systems, and automation.
